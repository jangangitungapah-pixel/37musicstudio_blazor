Montserrat body font hook

Place Montserrat web font files here and rename them to:

- montserrat-regular.woff2
- montserrat-medium.woff2
- montserrat-semibold.woff2
- montserrat-bold.woff2
- montserrat-extrabold.woff2

Recommended weights:
- 400 Regular: body text
- 500 Medium: input text
- 600 SemiBold: labels/subtle UI
- 700 Bold: buttons
- 800 ExtraBold: compact emphasis

Montserrat is commonly distributed under the SIL Open Font License.
This README is safe to commit. Font binary files are not created by this script.
