Victory Striker Sans Demo font hook

Place the licensed font file here and rename it to one of these names:

1. victory-striker-sans-demo.woff2
2. victory-striker-sans-demo.otf

Recommended:
- Use WOFF2 for web production.
- Keep the font only if your license allows web/app usage.
- The 1001 Fonts page lists the demo as free for personal use and not free for commercial use.

This README is safe to commit. Font binary files are not created by this script.
